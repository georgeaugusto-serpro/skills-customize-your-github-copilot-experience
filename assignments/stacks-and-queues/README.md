# 📘 Assignment: Stacks and Queues in Python

## 🎯 Objective

Implement stack and queue data structures from scratch using Python lists, and apply them to solve simple algorithmic problems without external libraries.

## 📝 Tasks

### 🛠️ Build a Stack class

#### Description
Create a `Stack` class that supports the standard operations and validates behavior for empty structures.

#### Requisitos
O programa concluído deve:

- Implement methods `push(value)`, `pop()`, `peek()`, and `is_empty()`
- Return a clear error message or raise an exception when `pop()` or `peek()` is called on an empty stack
- Include a small usage example that pushes at least 3 values and pops them in LIFO order
- Print or assert expected outputs for the example


### 🛠️ Build a Queue class and compare behavior

#### Description
Create a `Queue` class and demonstrate FIFO behavior by processing items in insertion order.

#### Requisitos
O programa concluído deve:

- Implement methods `enqueue(value)`, `dequeue()`, `front()`, and `is_empty()`
- Return a clear error message or raise an exception when `dequeue()` or `front()` is called on an empty queue
- Include a small usage example that enqueues at least 3 values and dequeues them in FIFO order
- Write 3-5 short lines explaining one practical use case for stack and one for queue
- Print or assert expected outputs for the example
